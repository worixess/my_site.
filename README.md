# ✿ FLOREA — цветы с чувством

**FLOREA** — авторский одностраничный сайт-визитка вымышленной цветочной студии. Сделан на чистых **HTML + CSS + JavaScript** без фреймворков, сборщиков и сервера.

> Сайт демонстрационный: букеты и студия придуманы для учебного проекта, реальные заказы не принимаются.

## 🔗 Ссылки

- **Сайт после публикации GitHub Pages:** https://andrey12-sys.github.io/My-repositories1/
- **Исходный код:** https://github.com/Andrey12-sys/My-repositories1

## ✨ Возможности

- Адаптивная верстка для компьютеров, планшетов и смартфонов.
- Авторские SVG-иллюстрации для главного экрана и шести букетов.
- Фильтрация коллекции по типу композиции: нежные, яркие, природные.
- Избранное: сохранение букетов в браузере через `localStorage`.
- Окно подборки: просмотр, удаление и копирование названий выбранных букетов.
- Мобильное выпадающее меню, плавное появление блоков при прокрутке и анимации.
- Индикатор прокрутки страницы и поддержка `prefers-reduced-motion`.
- Семантическая HTML-разметка, подписи к изображениям и доступные кнопки.

## ▶️ Как запустить локально

Скачайте репозиторий и откройте файл `index.html` в браузере. Для локального запуска сервер не требуется. Для корректной работы функции копирования списка браузер может требовать HTTPS или `localhost`.

## 🌍 Публикация в GitHub Pages

1. Откройте [Settings → Pages](https://github.com/Andrey12-sys/My-repositories1/settings/pages).
2. В разделе **Build and deployment** выберите `Deploy from a branch`.
3. Укажите ветку `main` и папку `/(root)`.
4. Нажмите **Save**.
5. После успешного развёртывания откройте: https://andrey12-sys.github.io/My-repositories1/
